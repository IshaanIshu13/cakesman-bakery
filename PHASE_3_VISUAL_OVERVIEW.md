## 🔄 Order Flow with Time Slot

```
START: User at Checkout
│
├─► FILL FORM
│   ├─ Name, Email, Phone
│   ├─ Delivery Type (Takeaway/Home)
│   ├─ Delivery Date
│   ├─ 🆕 DELIVERY TIME SLOT ............... NEW!
│   │    (Select from 4 options)
│   ├─ Address (if home delivery)
│   ├─ Special Instructions
│   ├─ Payment Method
│   └─ Agree to Terms
│
├─► VALIDATE
│   ├─ Check all required fields
│   ├─ 🆕 Validate time slot selected ... NEW!
│   └─ Show error if validation fails
│
├─► SUBMIT
│   ├─ Button shows "Processing..."
│   ├─ Button becomes disabled
│   ├─ Send order to backend with timeSlot
│   └─ Wait for response
│
├─► RESPONSE
│   ├─ SUCCESS
│   │  ├─ Show success toast
│   │  ├─ Clear cart
│   │  ├─ 🆕 Generate WhatsApp message ... NEW!
│   │  ├─ 🆕 Open WhatsApp with message . NEW!
│   │  └─ Navigate to home
│   │
│   └─ ERROR
│      ├─ Show error toast
│      ├─ Button re-enables
│      ├─ Form data preserved
│      └─ User can retry
│
└─► END: Order Complete or Ready to Retry
```
