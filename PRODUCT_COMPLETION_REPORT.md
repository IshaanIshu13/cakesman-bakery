## 📞 How to Use

### First Time Setup
```bash
# 1. Navigate to backend
cd backend

# 2. Seed the database
npm run seed

# 3. Start backend
npm start

# 4. In another terminal, start frontend
cd frontend
npm start

# 5. Visit website
http://localhost:3000
```

### Regular Operations
```bash
# View products in admin
http://localhost:3000/admin
# Login: admin@cakesman.com / admin123

# Manage products
```

## 📊 System Architecture

```
Frontend (React)
    ↓
    API Calls
    ↓
Backend (Express)
    ↓
    Database Queries
    ↓
MongoDB
    ↓
Products Collection (100 documents)
```

### Data Flow
1. User visits website → Frontend loads
2. Frontend makes API call to backend
3. Backend queries MongoDB
4. Returns 100 products organized by category
5. Frontend displays products
6. User selects product → Added to cart
7. Checkout uses product details
8. Order created with product info
